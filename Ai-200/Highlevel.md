### Complete AI-200 Exam Skills Breakdown

### 1. Develop AI Solutions Using Azure Data Services (25–30%)

This domain focuses on managing AI data efficiently for enterprise applications.

Topics include:

### Vector Search

- Vector embeddings
- Hybrid search
- Similarity search
- Distance metrics
- Semantic retrieval
- Retrieval-Augmented Generation (RAG)

### Azure Cosmos DB

Learn how to:

- Configure vector indexes
- Optimize partition keys
- Design indexing policies
- Improve query performance
- Handle massive document collections

### Azure Database for PostgreSQL

Candidates should understand:

- pgvector extension
- HNSW indexes
- IVFFlat indexes
- Vector similarity search
- Combining SQL filtering with vector search

### Azure Managed Redis

Knowledge areas include:

- Semantic caching
- Prompt caching
- Session storage
- Low-latency response optimization

---

### 2. Develop Containerized Solutions on Azure (25–30%)

Containerization is one of the largest portions of the AI-200 exam.

### Azure Container Apps

Understand:

- Container deployment
- Revisions
- Traffic splitting
- Ingress configuration
- Sidecar containers
- KEDA autoscaling

### Azure Kubernetes Service (AKS)

Topics include:

- Kubernetes clusters
- GPU node pools
- Horizontal Pod Autoscaler
- Rolling updates
- Resource optimization
- AI inference deployment

### Azure Container Registry

Candidates should know:

- Private repositories
- Automated builds
- Vulnerability scanning
- Image tagging
- Multi-architecture containers

---

### 3. Connect and Consume Azure Services (20–25%)

Enterprise AI systems rely heavily on asynchronous communication.

Important services include:

### Azure Event Grid

- Event routing
- Publish/Subscribe architecture
- Serverless event processing

### Azure Event Hubs

- Streaming data
- High-throughput ingestion
- Telemetry pipelines

### Azure Service Bus

Study:

- Queues
- Topics
- Dead-letter queues
- Message ordering
- Retry policies
- Transaction support

### Azure Functions

Understand:

- Blob triggers
- Timer triggers
- HTTP triggers
- Service Bus triggers
- Cosmos DB triggers
- Event Grid triggers

---

### 4. Secure, Monitor, and Troubleshoot Azure Solutions (20–25%)

Security remains a major exam objective.

Candidates should master:

### Managed Identity

- System-assigned identities
- User-assigned identities
- Secretless authentication

### Microsoft Entra ID

- Authentication
- Authorization
- OAuth
- RBAC

### Azure Key Vault

Protect:

- Secrets
- API keys
- Certificates
- Encryption keys

### Application Insights

Monitor:

- Exceptions
- Requests
- Dependencies
- Availability tests
- Performance metrics

### OpenTelemetry

Learn distributed tracing across multiple services.

### Kusto Query Language (KQL)

Practice:

- Log analysis
- Performance monitoring
- Troubleshooting
- Correlation IDs
- Query optimization
