#### Quick decision guide

- **Need raw TCP/UDP LB inside a region/VNet** → Azure Load Balancer
- **Need HTTP(S)-aware routing, WAF, SSL offload within a region** → Application Gateway
- **Need global HTTP(S) routing, CDN, WAF at the edge** → Front Door
- **Need simple DNS-based global failover/routing (non-HTTP too)** → Traffic Manager
- **Need to load balance across regions at L4** → Cross-region Load Balancer
